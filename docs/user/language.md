# Interface language

Open **Settings** -> **General** -> **Language** to choose **Follow system**, **English**, or
**Simplified Chinese**. The selection is saved on this device and applies immediately to the web
interface and the desktop app.

**Follow system** uses Simplified Chinese for `zh-CN`, `zh-SG`, and `zh-Hans` system locales.
Traditional Chinese locales currently use the English interface until a Traditional Chinese
translation is available.

The language setting changes T3 Code interface text. Model names, provider names, Git branches,
file paths, terminal output, agent responses, and original backend errors remain unchanged.
